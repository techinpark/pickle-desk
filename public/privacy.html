Pickle Desk 개인정보처리방침

시행일: 2026년 11월 3일 (방문 통계 항목 추가)

Pickle Desk(이하 "앱")는 사용자의 구글 드라이브에 있는 시트로 AI 비서에게 일을 맡기고 답변을 확인하는 오픈소스 웹 앱입니다. 앱에는 운영 서버가 없고, 모든 처리는 사용자의 브라우저에서 이루어집니다.

1. 받는 권한과 쓰는 곳

  • drive.file: 앱이 직접 만든 "Pickle Desk 작업함" 시트를 만들고, 읽고, 쓰는 데만 씁니다. 드라이브의 다른 파일은 볼 수 없습니다.
  • openid, email: 설정 화면에 로그인한 계정을 보여 주고, 다시 로그인할 때 같은 계정을 고르는 데 씁니다.

2. 저장하는 정보

  • 작업과 답변은 사용자 본인의 구글 시트에만 저장됩니다.
  • 구글 액세스 토큰(1시간 유효), 이메일 주소, 작업함 시트 ID, 화면 설정은 사용자 기기의 브라우저 저장소에만 남습니다. 로그아웃하면 토큰과 시트 ID를 지우고 토큰을 구글에 반납합니다.
  • 구글 API 로 받은 정보(이메일, 작업 내용, 시트 주소, 토큰)는 앱 개발자나 제3자에게 전송·판매·공유하지 않습니다. 광고는 없습니다.

2-1. 방문 통계 (Google Analytics)

  • 공식 배포 주소(techinpark.github.io/pickle-desk)는 몇 명이 쓰는지 알기 위해 Google Analytics 4 를 씁니다. Google Analytics 는 쿠키로 방문을 구분합니다.
  • 보내는 것: 화면 이름(로그인·작업함 만들기·메인), "로그인함·작업함 만듦·작업 보냄(분류)·문장 복사함" 같은 이벤트 이름, 홈 화면 앱 여부, 그리고 Google Analytics 가 기본으로 모으는 기기·브라우저·대략적인 지역 정보.
  • 보내지 않는 것: 이메일, 작업과 답변 내용, 시트 주소, 구글 토큰 등 구글 API 로 받은 모든 정보.
  • Google 신호와 광고 개인화는 꺼 두었습니다. 브라우저의 추적 방지 기능이나 Google Analytics 차단 부가기능으로 보내지 않게 할 수 있습니다.

2-2. 업데이트 요청 (Google Forms)

메뉴의 "업데이트 요청하기"는 구글 폼을 엽니다. 앱 버전·기기 종류·언어가 미리 채워지고, 적어 주신 내용과 (선택) 연락처만 개발자에게 전달됩니다. 이메일 주소는 자동으로 수집하지 않습니다.

3. 구글 사용자 데이터 정책 준수

앱이 구글 API 로 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

4. 권한 철회

앱에서 로그아웃하거나, Google 계정 → 보안 → 서드 파티 연결에서 Pickle Desk 의 접근 권한을 언제든 삭제할 수 있습니다. 작업함 시트는 드라이브에서 직접 지우면 됩니다.

Privacy Policy (English)

Pickle Desk is an open-source web app with no backend server. Everything runs in your browser.

  • Scopes: drive.file to create, read and write only the "Pickle Desk Tasks" sheet the app creates; openid and email to show your account and pick it again when signing back in.
  • Storage: tasks and replies live only in your own Google Sheet. The access token (valid for one hour), your email, the sheet ID and preferences are kept only in your browser's storage and are removed on sign-out.
  • Sharing: information received from Google APIs (email, task contents, sheet address, tokens) is never sent, sold or shared with the developer or any third party. No ads.
  • Usage analytics: the official deployment uses Google Analytics 4 (with cookies) to count usage. It sends screen names, event names such as "signed in", "created sheet", "sent task (category)", "copied prompt", whether the app runs from the home screen, and the device/browser/approximate location data Google Analytics collects by default. It never sends data received from Google APIs. Google signals and ad personalization are off. You can opt out with your browser's tracking protection or the Google Analytics opt-out add-on.
  • Update requests: "Request an update" in the menu opens a Google Form with the app version, device type and language pre-filled. Only what you write and an optional contact reach the developer; email addresses are not collected automatically.
  • Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: sign out, or remove Pickle Desk at myaccount.google.com/permissions.
  • Contact: GitHub issues.
