# 🥒 Pickle Desk

**한국어** · [English](README.en.md)

**구글 시트 하나로 AI 비서 피클에게 일을 맡기고, 답변을 휴대폰에서 바로 보는 앱.**

👉 **https://techinpark.github.io/pickle-desk/** 에서 바로 쓸 수 있습니다. 설치도, 서버도, 개발 지식도 필요 없습니다.

```
 Pickle Desk 앱  ──작업 적기──▶  내 구글 시트(Tasks)  ◀──5분마다 읽고 답 쓰기──  피클
       ▲                               │
       └──────── 답변·결과 자동 표시 ◀──┘
```

- 앱에서 "내일 회의록 정리해 줘"라고 적으면 내 구글 시트에 한 줄이 추가됩니다.
- 피클이 5분마다 시트를 확인해서 `Reply`(답변)·`Result`(결과)·`Status`(상태) 칸을 채웁니다.
- 앱이 몇 초마다 시트를 확인해서 답변을 채팅처럼 보여 줍니다.
- 홈 화면에 추가하면 앱처럼 쓸 수 있습니다(PWA). 다크 모드, 한국어·영어를 지원합니다.

> Pickle Desk 는 피클 개발사와 관계없는 비공식 오픈소스 프로젝트입니다.

## 시작하기 (1분)

### 1. 앱 열고 Google 로그인

1. 휴대폰에서 **https://techinpark.github.io/pickle-desk/** 를 엽니다.
2. **Google 계정으로 계속하기** 를 누르고 권한을 허용합니다.
   앱은 **자기가 만든 시트만** 열 수 있고, 드라이브의 다른 파일은 볼 수 없습니다(`drive.file` 권한).

### 2. 작업함 만들기

**작업함 만들기** 를 누르면 내 구글 드라이브에 `Pickle Desk 작업함` 시트가 생깁니다.

### 3. 피클에게 문장 보내기

1. **사전 준비**: 피클 앱에 **구글 계정(Google Workspace)** 이 연동되어 있는지 확인하세요. 연동되어 있지 않다면 피클에게 *"구글 연동해 줘"* 라고 말하면 연결 카드를 띄워 줍니다.
2. 작업함을 만들면 **피클 연결하기** 화면이 뜹니다. **문장 복사하기** 를 눌러 피클과의 대화창에 붙여 넣으세요. (나중에는 ≡ 메뉴 → **피클에게 보낼 문장** 에서 다시 볼 수 있습니다.)

복사되는 문장은 이렇게 생겼습니다. `<시트 링크>` 자리에 내 작업함 주소가 들어갑니다.

```text
이 구글 시트가 내 작업함이야: <시트 링크>
5분마다 Tasks 탭을 확인해서 자동으로 처리해 줘.
1. Status 가 pending 인 행을 위에서부터 확인해.
2. 작업을 시작할 때 Status 를 running 으로 바꿔.
3. 끝나면 Reply 에 한두 문장 요약 답을, Result 에 자세한 결과를 적고 Status 를 done 으로 바꿔.
4. 할 수 없으면 Reply 에 이유를 적고 Status 를 failed 로 바꿔.
5. 나에게 먼저 알려 줄 알림이나 제안이 있으면 새 행을 추가해서 Task 에 제목, Reply 에 내용을 적고 Status 를 done 으로 둬.
6. Id, Task, Category, CreatedAt 칸은 고치지 마. 새 행의 Id 는 비워 두면 돼.
7. Task 에 구글 드라이브 이미지 링크가 있으면 그 이미지를 열어 보고 작업에 참고해.
```

처음 연결할 때 **지난 기록도 가져올까요?** 에서 기간(최근 7일·30일)을 고르면, 문장 끝에 이런 줄이 붙어서 피클이 그동안 맡긴 일과 결과를 시트에 한 번 채워 줍니다(7일을 고른 경우).

```text
8. 처음 한 번만: 최근 7일 동안 내가 너에게 맡긴 일과 그 결과를 기억나는 만큼 새 행으로 추가해 줘. Task 에 맡긴 일, Reply 에 한두 문장 결과, Result 에 자세한 결과를 적고, Status 는 done(끝내지 못한 일은 failed), Category 는 task, CreatedAt 에는 그 일을 맡긴 날짜와 시각을 YYYY-MM-DD HH:mm:ss 로 적어. 오래된 것부터 차례로 넣고 Id 는 비워 둬.
```

피클이 얼마나 채울지는 피클이 지난 대화를 얼마나 기억하느냐에 달려 있습니다.

👉 피클이 시트를 인식하고, 5분마다 확인하는 백그라운드 스케줄을 스스로 등록합니다. 이제 앱에서 일을 맡기면 피클이 알아서 처리하고 결과를 채워 줍니다.

### 4. 홈 화면에 추가 (선택)

아이폰은 Safari 공유 버튼 → **홈 화면에 추가**, 안드로이드는 Chrome 메뉴 → **앱 설치** 를 누르면 앱처럼 쓸 수 있습니다.

## 시트 규칙

| 칸 | 누가 쓰나 | 내용 |
| --- | --- | --- |
| `Id` | 자동 | 작업 번호. 피클이 비워 두면 앱이 채웁니다. |
| `Task` | 앱 | 맡긴 일 |
| `Status` | 피클 | `pending`(대기) · `running`(진행 중) · `done`(완료) · `failed`(실패). `대기`·`진행 중`·`완료`·`실패` 처럼 한국어로 적어도 됩니다. |
| `Category` | 앱 | `task` · `briefing` · `idea` · `quick_action` |
| `Reply` | 피클 | 말풍선으로 보이는 짧은 답 |
| `Result` | 피클 | 접어서 보이는 자세한 결과. 링크는 눌러서 열 수 있습니다. |
| `CreatedAt` | 앱 | 만든 시각 |
| `UpdatedAt` | 피클(선택) | 고친 시각 |

칸 이름과 순서(`A:H`), 탭 이름(`Tasks`)은 바꾸지 마세요. 피클은 `Tasks!A:H` 범위를 읽고 `C:F`(Status·Category·Reply·Result)를 고쳐 씁니다.

## 자주 묻는 질문

**내 데이터는 어디로 가나요?**
작업과 답변은 **내 구글 시트에만** 저장됩니다. 앱은 휴대폰 브라우저에서 구글 시트 API 로 직접 요청하고, 중간 서버는 없습니다. 공식 배포 주소는 사용자 수를 세려고 Google Analytics 를 쓰지만, 이메일·작업 내용·시트 주소는 보내지 않습니다. 자세한 내용은 [개인정보처리방침](https://techinpark.github.io/pickle-desk/privacy.html)을 보세요.

**다른 기기에서도 쓸 수 있나요?**
같은 구글 계정으로 로그인하면 예전에 만든 작업함을 자동으로 찾아서 이어 씁니다.

**답변이 늦게 보여요.**
피클은 5분마다 시트를 확인하므로, 맡긴 뒤 처리가 시작되기까지 최대 5분쯤 걸립니다. 급하면 피클에게 *"작업함 지금 확인해 줘"* 라고 말하세요.
피클이 답을 적은 뒤에는 앱이 새로고침 주기(설정에서 5~30초)마다 가져옵니다. 앱을 닫아 두면 확인하지 않고, 다시 열면 바로 확인합니다.

**답변이 오면 알림을 받을 수 있나요?**
설정 → **답변 알림** 을 켜면, 앱을 내려 둔 동안 피클이 답할 때 휴대폰·PC 알림으로 알려 줍니다. 앱이 살아 있는 동안 30초마다 시트를 확인하는 방식이라 앱을 완전히 닫으면 오지 않습니다. 아이폰은 홈 화면에 추가한 앱(iOS 16.4 이상)에서만 쓸 수 있고, 백그라운드로 가면 곧 멈춰서 잘 안 올 수 있습니다. PC 브라우저와 안드로이드에서 가장 잘 동작합니다.

**가끔 구글 화면이 잠깐 보였다가 돌아와요.**
브라우저 앱이라 구글 로그인이 1시간마다 만료됩니다. 만료되면 앱이 구글을 잠깐 거쳐 새로 받아 옵니다. 이미 허용한 계정이면 누를 것은 없습니다.

**원하는 기능이 있어요 / 안 되는 게 있어요.**
≡ 메뉴 → **업데이트 요청하기** 를 누르면 로그인 없이 쓸 수 있는 요청 양식이 열립니다. 개발자는 [GitHub 이슈](https://github.com/techinpark/pickle-desk/issues)도 환영합니다.

**사진도 같이 보낼 수 있나요?**
입력창의 사진 버튼으로 이미지를 최대 4장까지 붙일 수 있습니다. 사진은 내 구글 드라이브의 `Pickle Desk 첨부` 폴더에 올라가고(공유 설정은 바꾸지 않음), 작업 칸에 드라이브 링크가 함께 적혀 피클이 열어 봅니다. 이 기능이 생기기 전에 피클을 연결했다면 ≡ 메뉴 → **피클에게 보낼 문장** 을 피클에게 한 번 더 보내 주세요(7번 줄이 새로 생겼습니다).

**시트를 지웠어요.**
앱에 "작업함 시트가 지워졌어요"가 뜨면 **다시 설정** 을 눌러 새로 만들고, 피클에게 새 문장을 보내세요.

## 개발자용

Vite + React + TypeScript PWA. 백엔드 없이 브라우저에서 구글 시트·드라이브 API 를 직접 부릅니다.

```sh
npm install
echo "VITE_GOOGLE_CLIENT_ID=<OAuth 클라이언트 ID>" > .env.local
npm run dev     # http://localhost:5173
npm run check   # tsc + oxlint + vitest + build
npm run e2e     # 실제 브라우저 E2E (데스크톱·모바일, 구글 API 는 가짜). Node 22.22.3+ 필요
```

- **로그인**: OAuth 2.0 클라이언트 측 흐름(`response_type=token`)을 리디렉트로 씁니다. iOS 홈 화면 앱에서는 팝업이 돌아오지 못해서입니다. 토큰이 만료되면 `prompt=none` 으로 조용히 다시 받고, `state` 로 꾸민 응답을 막습니다.
- **권한**: `drive.file`(앱이 만든 파일만), `openid`, `email`. 모두 구글 분류상 민감하지 않은 권한이라 앱 심사가 필요 없습니다.
- **작업함 찾기**: 만들 때 Drive `appProperties` 에 `pickleDesk=tasks` 를 달아 두고, 다른 기기에서 로그인하면 그걸로 찾습니다.
- **배포**: `main` 에 푸시하면 GitHub Actions 가 GitHub Pages 로 배포합니다(`BASE_PATH=/pickle-desk/`). 레포 변수 `GOOGLE_CLIENT_ID` 와 (선택) `GA_MEASUREMENT_ID` 가 빌드에 들어갑니다. `GA_MEASUREMENT_ID` 가 비어 있으면 통계 코드를 아예 불러오지 않습니다.
- **할당량**: 시트 API 기본 할당량은 프로젝트당 분당 읽기 300회입니다. 5초 주기면 동시 사용자 약 25명이라, 사용자가 늘면 Google Cloud 콘솔에서 할당량 증가를 신청하세요(무료).

### 직접 호스팅하기 (포크)

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만들고 **Google Sheets API**, **Google Drive API** 를 켭니다.
2. **Google 인증 플랫폼**에서 앱 이름·지원 이메일·홈페이지·개인정보처리방침(`/privacy.html`)을 채우고, 데이터 액세스에 `drive.file`, `openid`, `email` 을 추가한 뒤 **게시**합니다.
3. **클라이언트 → 웹 애플리케이션**을 만들고, 승인된 자바스크립트 원본·리디렉션 URI 에 내 주소(예: `https://<me>.github.io` 와 `https://<me>.github.io/pickle-desk/`)를 넣습니다.
4. 클라이언트 ID 를 레포 변수 `GOOGLE_CLIENT_ID` 에 넣고 GitHub Pages 소스를 "GitHub Actions"로 바꿉니다. 방문 통계가 필요하면 GA4 측정 ID 를 `GA_MEASUREMENT_ID` 에 넣고 `public/privacy.html` 의 통계 항목을 내 배포에 맞게 고칩니다.
