# 🥒 Pickle Jar

**구글 시트 하나로 AI 비서 피클에게 일을 맡기고, 답변을 휴대폰에서 바로 보는 앱.**

서버도, 데이터베이스도, 개발 지식도 필요 없습니다. 구글 시트가 피클과 앱 사이의 "작업함" 역할을 합니다.

```
 휴대폰 앱(Pickle Jar)  ──작업 적기──▶  구글 시트(Tasks)  ◀──읽고 답 쓰기──  피클
        ▲                                     │
        └────────── 답변·결과 자동 표시 ◀─────┘
```

- 앱에서 "내일 회의록 정리해 줘"라고 적으면 시트에 한 줄이 추가됩니다.
- 피클이 그 줄을 읽고 `Reply`(답변)·`Result`(결과)·`Status`(상태) 칸을 채웁니다.
- 앱이 몇 초마다 시트를 확인해서 답변을 채팅처럼 보여 줍니다.
- 홈 화면에 추가하면 앱처럼 쓸 수 있습니다(PWA). 다크 모드, 한국어·영어를 지원합니다.

> Pickle Jar 는 피클 개발사와 관계없는 비공식 오픈소스 프로젝트입니다. 시트를 읽고 쓸 수 있는 AI 비서나 사람이면 누구나 반대편에 붙일 수 있습니다.

## 시작하기 (10분, 개발 지식 필요 없음)

### 1단계. 구글 시트 만들기

1. [sheets.new](https://sheets.new) 에서 새 시트를 만들고 이름을 정합니다(예: `피클 작업함`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 편집기에 있는 내용을 모두 지우고, 이 레포의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 복사해 붙여 넣습니다.
4. 💾 저장(⌘S / Ctrl+S)합니다.

### 2단계. 시트 준비하기

1. 시트 탭으로 돌아와 새로고침하면 위쪽 메뉴에 **🥒 Pickle Jar** 가 생깁니다.
2. **🥒 Pickle Jar → 1. 시트 준비하기** 를 누릅니다.
3. 처음 한 번은 구글이 권한을 묻습니다. **계속 → 내 계정 선택 → 고급 → (안전하지 않은 페이지로 이동) → 허용**을 누르세요.
   직접 붙여 넣은 스크립트라 구글 검토를 받지 않아서 나오는 경고이고, 스크립트는 **이 시트에만** 접근합니다.
4. `Tasks` 탭이 생기고 머리글(`Id, Task, Status, Category, Reply, Result, CreatedAt, UpdatedAt`)이 채워집니다.

### 3단계. 웹 앱으로 배포하기

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 톱니바퀴 ⚙️ 에서 유형을 **웹 앱** 으로 고릅니다.
3. 아래처럼 설정하고 **배포** 를 누릅니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
4. "모든 사용자"여도 **연결 키가 없으면 아무것도 읽거나 쓸 수 없습니다.** 키는 시트마다 무작위로 만들어집니다.

### 4단계. 휴대폰 연결하기

1. 시트에서 **🥒 Pickle Jar → 2. 휴대폰 연결하기** 를 누릅니다.
2. 휴대폰 카메라로 QR 코드를 찍으면 앱이 열리면서 바로 연결됩니다.
3. 아이폰은 Safari 공유 버튼 → **홈 화면에 추가**, 안드로이드는 Chrome 메뉴 → **앱 설치** 를 누르면 앱처럼 쓸 수 있습니다.

> QR 이 안 되면 창에 나온 링크를 휴대폰으로 보내서 여세요. 이 링크는 **비밀번호와 같으니** 다른 사람에게 보내지 마세요.
> 링크가 새어 나갔다면 **🥒 Pickle Jar → 연결 키 새로 만들기** 를 누르면 예전 링크는 바로 막힙니다.

### 5단계. 피클에게 시트 알려 주기

1. **사전 준비**: 피클 앱에 **구글 계정(Google Workspace)** 이 연동되어 있는지 확인하세요. 연동되어 있지 않다면 피클에게 *"구글 연동해 줘"* 라고 말하면 연결 카드를 띄워 줍니다.
2. 시트에서 **🥒 Pickle Jar → 3. 피클에게 보낼 문장 복사** 를 누르면, 이 시트 링크가 들어간 아래 문장이 나옵니다. 그대로 복사해서 피클과의 대화창에 보내세요.

```text
이 구글 시트가 내 작업함이야: <시트 링크>
5분마다 Tasks 탭을 확인해서 자동으로 처리해 줘.
1. Status 가 pending 인 행을 위에서부터 확인해.
2. 작업을 시작할 때 Status 를 running 으로 바꿔.
3. 끝나면 Reply 에 한두 문장 요약 답을, Result 에 자세한 결과를 적고 Status 를 done 으로 바꿔.
4. 할 수 없으면 Reply 에 이유를 적고 Status 를 failed 로 바꿔.
5. 나에게 먼저 알려 줄 알림이나 제안이 있으면 새 행을 추가해서 Task 에 제목, Reply 에 내용을 적고 Status 를 done 으로 둬.
6. Id, Task, Category, CreatedAt 칸은 고치지 마. 새 행의 Id 는 비워 두면 돼.
```

👉 피클이 시트를 인식하고, 5분마다 확인하는 백그라운드 스케줄을 스스로 등록합니다. 이제 휴대폰 앱(Pickle Jar)에서 일을 맡기면 피클이 알아서 처리하고 결과를 채워 줍니다.

> 피클은 구글 연동으로 **내 계정의 시트를 직접** 읽고 쓰기 때문에 시트를 따로 공유하거나 API 키를 만들 필요가 없습니다.

## 시트 규칙

| 칸 | 누가 쓰나 | 내용 |
| --- | --- | --- |
| `Id` | 자동 | 작업 번호. 비워 두면 자동으로 채워집니다. |
| `Task` | 앱 | 맡긴 일 |
| `Status` | 피클 | `pending`(대기) · `running`(진행 중) · `done`(완료) · `failed`(실패). `대기`·`진행 중`·`완료`·`실패` 처럼 한국어로 적어도 됩니다. |
| `Category` | 앱 | `task` · `briefing` · `idea` · `quick_action` |
| `Reply` | 피클 | 말풍선으로 보이는 짧은 답 |
| `Result` | 피클 | 접어서 보이는 자세한 결과. 링크는 눌러서 열 수 있습니다. |
| `CreatedAt` | 자동 | 만든 시각 |
| `UpdatedAt` | 자동 | 시트에서 직접 고친 시각 |

칸 이름과 순서(`A:H`)는 바꾸지 마세요. 피클은 `Tasks!A:H` 범위를 읽고 `C:F`(Status·Category·Reply·Result)를 고쳐 씁니다.

## 자주 묻는 질문

**"시트가 앱에 열려 있지 않아요"라고 나와요.**
웹 앱 배포의 액세스 권한이 "모든 사용자"인지 확인하세요. 바꿨다면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 로 다시 배포합니다.

**`Code.gs` 를 새 버전으로 바꿨어요.**
붙여 넣고 저장한 뒤 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 누르세요. 주소와 연결 키는 그대로입니다.

**내 데이터는 어디로 가나요?**
작업과 답변은 **내 구글 시트에만** 저장됩니다. 앱은 휴대폰 브라우저에서 내 시트의 Apps Script 로 직접 요청하고, 중간 서버는 없습니다. 연결 키는 휴대폰 브라우저 저장소에만 남습니다.

**답변이 늦게 보여요.**
피클은 5분마다 시트를 확인하므로, 맡긴 뒤 처리가 시작되기까지 최대 5분쯤 걸립니다. 급하면 피클에게 *"작업함 지금 확인해 줘"* 라고 말하세요.
피클이 답을 적은 뒤에는 앱이 새로고침 주기(설정에서 5~30초)마다 가져옵니다. 앱을 닫아 두면 확인하지 않고, 다시 열면 바로 확인합니다.

## 개발자용

Vite + React + TypeScript PWA. 백엔드는 시트에 붙은 Apps Script 웹 앱(`apps-script/Code.gs`) 하나입니다.

```sh
npm install
npm run dev     # http://localhost:5173
npm run check   # tsc + oxlint + vitest + build
npm run e2e     # 실제 브라우저 E2E (데스크톱·모바일). Node 22.22.3+ 필요
```

- 앱 ↔ Apps Script: `GET ?action=list&key=…&limit=30&beforeId=…`, `POST {"action":"create","key":"…","task":"…","category":"…"}`.
  Apps Script 는 CORS 사전 요청(OPTIONS)을 받지 못해서, 사용자 정의 헤더 없이 키를 쿼리·본문에 넣고 POST 는 `text/plain` 으로 보냅니다.
- 연결 링크 `…/#connect?u=<웹 앱 주소>&k=<키>` 는 `#` 뒤에 있어 앱 호스팅 서버로 전달되지 않고, 앱이 읽은 뒤 주소창에서 지웁니다.
- `main` 에 푸시하면 GitHub Actions 가 GitHub Pages 로 배포합니다(`BASE_PATH=/pickle-jar/`). 포크해서 직접 호스팅한다면 `apps-script/Code.gs` 의 `APP_URL` 을 내 주소로 바꾸세요.
- `apps-script/Code.test.ts` 는 가짜 `SpreadsheetApp` 위에서 `Code.gs` 를 돌려 키 확인·목록·등록을 검사합니다.
